# 연구계획서 — (연구 제목: 예) 단백질·분자 ○○ 예측·설계 모델)

## 1. 연구 목표
- 풀려는 생물·화학 문제(예: 결합 친화도 예측, 단백질 구조·기능 예측, 분자 생성):
- 예측·생성 대상과 단위(예: pKd, ΔΔG kcal/mol):
- 가설과 성공 기준(수치):

## 2. 방법
- 모델 구조(예: 단백질 언어모델, 구조 기반 GNN, 확산 생성모델)와 입력 표현(서열·구조·SMILES):
- 사전학습 모델 사용 여부와 미세조정 방식:
- 비교 기준선(baseline)과 선정 이유:
- 절제 실험(ablation) 계획:

## 3. 데이터
- 데이터셋 이름·출처·버전·라이선스(예: PDB, ChEMBL, BindingDB, UniProt):
- 규모(서열·복합체·분자 수)와 라벨 측정 방법(실험 분석법):
- 분할 방식(서열 유사도·스캐폴드·표적 기준 분할, 사전학습 데이터와 테스트셋 중복 점검):
- 결측·이상치·중복 측정값 처리:

## 4. 평가
- 지표(Spearman, AUROC, RMSD 등)와 반복 실행 수·오차 막대:
- 학습에 없던 표적·스캐폴드에 대한 일반화 시험:
- 생성 분자·서열의 타당성·다양성·합성 가능성 평가:
- 습식 실험(wet-lab) 검증 계획:

## 5. 일정
- 1~3개월: 데이터 수집·정제, 분할 설계
- 4~6개월: 모델 구현, 기준선 비교
- 7~12개월: 일반화 시험·실험 검증, 코드·데이터 공개
