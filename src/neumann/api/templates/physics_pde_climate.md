# 연구계획서 — (연구 제목: 예) 신경 연산자로 ○○ 방정식 대리모델)

## 1. 연구 목표
- 풀려는 물리 문제와 지배 방정식(예: Navier-Stokes, 열전달, 기후 모델 변수):
- 예측 대상 물리량·해상도·예측 시간 범위:
- 가설과 성공 기준(수치, 예: 상대 L2 오차 ≤ ○○%, 수치해석 대비 속도 ○○배):

## 2. 방법
- 모델 구조(예: Fourier Neural Operator, PINN, 그래프 기반 시뮬레이터)와 입력·출력 격자:
- 물리 제약(보존 법칙·경계 조건) 반영 방식:
- 비교 기준선(수치해석 솔버, 기존 대리모델)과 선정 이유:
- 절제 실험(ablation) 계획:

## 3. 데이터
- 데이터 출처(시뮬레이션 코드·설정, 재분석 자료 예: ERA5)·버전·라이선스:
- 규모(궤적·샘플 수), 해상도, 매개변수 범위:
- 분할 방식(시간 순서 분할, 매개변수·지역 기준 분할, 인접 시점 누출 점검):
- 정규화·결측 처리:

## 4. 평가
- 지표(상대 L2, RMSE, ACC 등)와 반복 실행 수·오차 막대:
- 장기 예측(롤아웃) 안정성과 오차 누적:
- 학습 범위 밖 매개변수·해상도·기후 조건에 대한 일반화 시험:
- 계산 비용(학습·추론 시간, 하드웨어) 비교:

## 5. 일정
- 1~3개월: 시뮬레이션·자료 준비, 분할 설계
- 4~6개월: 모델 구현, 솔버·기준선 비교
- 7~12개월: 일반화·장기 안정성 시험, 코드·데이터 공개
