# 연구계획서 — (연구 제목: 예) fMRI 기반 ○○ 디코딩·분류)

## 1. 연구 목표
- 풀려는 신경과학 질문(예: 인지과제 디코딩, 뇌 연결성 기반 예측):
- 예측 대상(과제 유형·행동 점수·임상 변수):
- 가설과 성공 기준(수치):

## 2. 방법
- 전처리 파이프라인(도구·버전, 움직임 보정, 공간 정규화, 평활화):
- 특징 추출(ROI·아틀라스, 연결성, ICA)과 모델(선형 분류기, 딥러닝):
- 비교 기준선(baseline)과 선정 이유:
- 교란 변수(머리 움직임·나이·장비·사이트) 통제 방법:

## 3. 데이터
- 데이터셋 이름·출처·버전·라이선스(예: OpenNeuro, HCP):
- 참가자 수·스캔 조건·과제 설계, 윤리 승인·동의 범위:
- 분할 방식(참가자 단위 분할, 같은 참가자 세션 누출 점검, 사이트 기준 분할):
- 제외 기준(움직임 역치 등)과 사전 등록 여부:

## 4. 평가
- 지표(정확도, AUROC, 상관)와 교차검증 방식·반복 수·오차 막대:
- 순열 검정 등 통계적 유의성과 다중 비교 보정:
- 다른 사이트·데이터셋에 대한 일반화 시험:
- 해석(가중치·활성화 지도)의 신뢰성 점검:

## 5. 일정
- 1~3개월: 데이터 수집·전처리, 분할 설계
- 4~6개월: 특징·모델 구현, 기준선 비교
- 7~12개월: 일반화·통계 검정, 코드 공개
