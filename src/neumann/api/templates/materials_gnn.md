# 연구계획서 — (연구 제목: 예) GNN 대리모델로 ○○ 물성 예측)

## 1. 연구 목표
- 풀려는 과학 문제:
- 예측 대상 물성과 단위(예: 이온전도도 mS/cm, 형성에너지 eV/atom):
- 가설과 성공 기준(수치, 예: 테스트 MAE ≤ ○○):

## 2. 방법
- 모델 구조(예: 메시지 전달 GNN, 등변 GNN)와 입력 표현(분자 그래프·결정 구조·조성):
- 비교 기준선(baseline)과 선정 이유:
- 절제 실험(ablation) 계획:
- 하이퍼파라미터 탐색 범위와 선택 기준(검증셋 기준):

## 3. 데이터
- 데이터셋 이름·출처·버전·라이선스(예: Materials Project, OQMD, 실험 DB):
- 규모(구조·조성 수)와 라벨 산출 방법(DFT 계산 조건·실험 측정 조건):
- 분할 방식(조성·구조 군 기준 분할 여부, 중복·유사 구조 누출 점검):
- 결측·이상치 처리:

## 4. 평가
- 지표(MAE, RMSE, R² 등)와 반복 실행 수·오차 막대:
- 분포 밖(OOD) 조성·구조에 대한 일반화 시험:
- 불확실성 추정과 보정(calibration):
- 실험 검증 또는 외부 테스트셋:

## 5. 일정
- 1~3개월: 데이터 수집·정제, 분할 설계
- 4~6개월: 모델 구현, 기준선 비교
- 7~12개월: 일반화·실험 검증, 코드·데이터 공개
