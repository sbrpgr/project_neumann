# 연구계획서 — (연구 제목: 예) ○○ 반응 수율·생성물 예측 모델)

## 1. 연구 목표
- 풀려는 화학 문제(예: 반응 생성물 예측, 역합성 경로 탐색, 수율·선택성 예측, 분자 물성 예측):
- 예측 대상과 단위(예: top-k 정확도, 수율 %, 활성화 에너지 kcal/mol):
- 가설과 성공 기준(수치):

## 2. 방법
- 모델 구조(예: 그래프 신경망, Transformer 기반 SMILES 모델, 반응 템플릿 기반 모델)와 입력 표현(SMILES·분자 그래프·3차원 구조):
- 사전학습 모델 사용 여부와 미세조정 방식:
- 비교 기준선(템플릿 기반·기존 공개 모델)과 선정 이유:
- 절제 실험(ablation) 계획:

## 3. 데이터
- 데이터셋 이름·출처·버전·라이선스(예: USPTO, Reaxys, ORD, QM9):
- 규모(반응·분자 수)와 라벨 산출 방법(실험 보고값·양자화학 계산 조건):
- 분할 방식(반응 유형·스캐폴드·시간 기준 분할, 같은 반응의 중복·원자 매핑 오류 점검):
- 결측·이상치·중복 반응 처리:

## 4. 평가
- 지표(top-k 정확도, MAE, 유효 분자 비율)와 반복 실행 수·오차 막대:
- 학습에 없던 반응 유형·스캐폴드에 대한 일반화 시험:
- 예측 경로·생성물의 화학적 타당성과 합성 가능성 평가:
- 실험 검증 또는 외부 테스트셋:

## 5. 일정
- 1~3개월: 데이터 수집·정제, 분할 설계
- 4~6개월: 모델 구현, 기준선 비교
- 7~12개월: 일반화·실험 검증, 코드·데이터 공개
