# 연구계획서 — (연구 제목: 예) ○○ 표적 단백질 구조·결합 예측 모델)

## 1. 연구 목표
- 풀려는 생물·신약 문제(예: 단백질-리간드 결합 친화도, 결합 포즈, 단백질 구조·복합체 예측):
- 예측 대상과 단위(예: pKd·pKi, ΔG kcal/mol, 포즈 RMSD Å):
- 가설과 성공 기준(수치, 예: 새 표적 Spearman ≥ ○○, RMSD < 2Å 비율 ○○%):

## 2. 방법
- 모델 구조(예: 등변 GNN, 구조 기반 확산 모델, 단백질 언어모델)와 입력 표현(서열·3차원 구조·포켓·SMILES):
- 사전학습 모델 사용 여부와 미세조정 방식:
- 비교 기준선(도킹 점수 함수, 최근 딥러닝 모델)과 선정 이유:
- 절제 실험(ablation) 계획:

## 3. 데이터
- 데이터셋 이름·출처·버전·라이선스(예: PDBbind, BindingDB, ChEMBL, PDB):
- 규모(복합체·화합물 수)와 라벨 측정 방법(실험 분석법, 도킹·예측 구조 사용 여부):
- 분할 방식(서열 유사도·스캐폴드·표적 기준 분할, 벤치마크 버전 간 중복 복합체 제거):
- 결측·이상치·중복 측정값 처리:

## 4. 평가
- 지표(Pearson·Spearman, RMSE, 포즈 성공률, 농축 계수)와 반복 실행 수·오차 막대:
- 학습에 없던 표적·스캐폴드에 대한 일반화 시험:
- 예측 구조·도킹 포즈를 입력으로 쓸 때의 성능 저하:
- 습식 실험(wet-lab) 검증 또는 외부 테스트셋:

## 5. 일정
- 1~3개월: 데이터 수집·정제, 누출 없는 분할 설계
- 4~6개월: 모델 구현, 기준선 비교
- 7~12개월: 새 표적 일반화·실험 검증, 코드·데이터 공개
