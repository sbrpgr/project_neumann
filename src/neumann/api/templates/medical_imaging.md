# 연구계획서 — (연구 제목: 예) ○○ 영상 기반 ○○ 검출·분류 모델)

## 1. 연구 목표
- 풀려는 임상 문제와 사용 장면(선별·진단 보조·예후 예측):
- 예측 대상(병변 검출·분류·분할)과 기준 진단(reference standard):
- 가설과 성공 기준(수치, 예: 민감도 ≥ ○○% 에서 특이도):

## 2. 방법
- 모델 구조(예: CNN, Vision Transformer, 분할 네트워크)와 입력 전처리:
- 사전학습 가중치 사용 여부와 미세조정 방식:
- 비교 기준선(기존 모델, 판독의 성능)과 선정 이유:
- 절제 실험(ablation)과 해석(주의 지도) 계획:

## 3. 데이터
- 데이터셋 이름·출처·버전·라이선스(공개 데이터 또는 기관 데이터, IRB 승인):
- 환자·영상 수, 장비·기관 구성, 라벨링 방법(판독의 수·합의 방식):
- 분할 방식(환자 단위 분할, 같은 환자 영상 누출 점검, 기관 기준 외부 검증셋):
- 클래스 불균형과 결측 처리, 개인정보 비식별화:

## 4. 평가
- 지표(AUROC, 민감도·특이도, Dice 등)와 신뢰구간·반복 수:
- 외부 기관 데이터에 대한 일반화 시험:
- 하위군(성별·나이·장비) 성능 차이와 보정(calibration):
- 판독의 대비 또는 전향적 평가 계획, 보고 지침(예: CLAIM, TRIPOD+AI) 준수:

## 5. 일정
- 1~3개월: 데이터 확보·IRB, 라벨링·분할 설계
- 4~6개월: 모델 구현, 기준선 비교
- 7~12개월: 외부 검증·하위군 분석, 코드 공개
