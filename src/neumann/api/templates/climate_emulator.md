# 연구계획서 — (연구 제목: 예) ○○ 기후·기상 변수 AI 에뮬레이터)

## 1. 연구 목표
- 풀려는 지구과학 문제(예: 중기 기상 예측, 기후 시나리오 에뮬레이션, 강수·극한 현상 다운스케일링):
- 예측 대상 변수·공간 해상도·예측 기간(예: 500hPa 지위고도, 0.25°, 10일):
- 가설과 성공 기준(수치, 예: 5일 예측 RMSE가 수치 예보 대비 ○○% 이내):

## 2. 방법
- 모델 구조(예: 그래프 기반 예보 모델, 신경 연산자, Transformer, 확산 모델)와 입력 변수·격자:
- 물리 제약(에너지·질량 수지) 반영 방식과 앙상블·확률 예측 방식:
- 비교 기준선(수치 예보 IFS, 기후 모델, 기존 AI 예보 모델)과 선정 이유:
- 절제 실험(ablation) 계획:

## 3. 데이터
- 데이터 출처·버전·라이선스(예: ERA5 재분석, CMIP6, 관측소 자료, WeatherBench):
- 규모(기간·변수·격자), 시간 간격, 전처리(재격자화·정규화):
- 분할 방식(연도 단위 시간 분할, 학습·평가 기간 겹침 점검, 지역·시나리오 기준 분할):
- 결측·관측 편향 처리:

## 4. 평가
- 지표(RMSE, ACC, CRPS, 극한 현상 적중률)와 반복 실행 수·오차 막대:
- 장기 롤아웃 안정성, 기후 통계(평균·변동성·스펙트럼) 재현:
- 학습 기간 밖 기후 조건(온난화 시나리오, 극한 사례)에 대한 일반화 시험:
- 수치 모델 대비 계산 비용(학습·추론 시간, 하드웨어) 비교:

## 5. 일정
- 1~3개월: 자료 수집·재격자화, 기간 분할 설계
- 4~6개월: 모델 구현, 수치 예보·기준선 비교
- 7~12개월: 장기 안정성·극한 사례 평가, 코드·데이터 공개
