# 연구계획서 — (연구 제목: 예) 신경 연산자로 ○○ 방정식 대리모델)

## 1. 연구 목표
- 풀려는 물리 문제와 지배 방정식(예: Navier-Stokes, 반응-확산, 탄성·열전달):
- 예측 대상 물리량·격자·해상도·예측 시간 범위:
- 가설과 성공 기준(수치, 예: 상대 L2 오차 ≤ ○○%, 같은 정확도에서 수치 해법 대비 속도 ○○배):

## 2. 방법
- 모델 구조(예: Fourier Neural Operator, DeepONet, PINN, 그래프 기반 시뮬레이터)와 입력·출력 격자:
- 물리 제약(보존 법칙·경계 조건·비발산 조건) 반영 방식:
- 비교 기준선(수치 해법, 기존 신경 연산자)과 선정 이유:
- 절제 실험(ablation) 계획:

## 3. 데이터
- 시뮬레이션 코드·수치 기법·설정(격자, 시간 간격, 매개변수 범위)과 공개 벤치마크(예: PDEBench):
- 규모(궤적·샘플 수), 해상도, 초기·경계 조건 생성 방식:
- 분할 방식(궤적 단위 분할, 매개변수 범위 밖 테스트, 같은 궤적 인접 시점 누출 점검):
- 정규화 방식:

## 4. 평가
- 지표(상대 L2, RMSE, 스펙트럼 오차)와 반복 실행 수(시드)·오차 막대:
- 장기 롤아웃 안정성과 오차 누적:
- 보존량(질량·에너지·운동량) 오차 검증:
- 학습과 다른 해상도·매개변수에 대한 일반화 시험:
- 수치 해법 대비 같은 정확도에서의 계산 비용(학습·추론 시간, 하드웨어):

## 5. 일정
- 1~3개월: 시뮬레이션 데이터 생성, 분할 설계
- 4~6개월: 모델 구현, 수치 해법·기준선 비교
- 7~12개월: 일반화·장기 안정성 시험, 코드·데이터 공개
