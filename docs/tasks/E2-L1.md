# E2-L1 — 검색 보정(점수 하한·질의 결합·한국어 질의)
- 빌더 Opus 5.5 · 검증 Sonnet 5.5 · 목표 50분 · 소유: `src/neumann/index/`, `scripts/build_index*`, `tests/e2/`
## 근거
E2-L0 검증(docs/reports/E2-L0.verify.md): 한국어 계획서 전문은 분야까지만 맞춤(가장 가까운 두 편이 92·109위), 점수 하한 0.30은 짧은 한국어 질의를 자름, 질의별 최댓값 결합은 한 질의가 상위 10편을 독점할 수 있음. 계획서 §3 L1 "하이브리드 정교화"
## 만들 것
1. 여러 질의 결합: 최댓값 대신 질의별 순위 융합(RRF 등)과 질의별 상위 할당, 선택 가능하게(설정)
2. 점수 하한 실측 보정: 관련/무관 질의 세트(데모 3건·조리법·짧은 한국어 5쌍)로 분리점 측정, 하한과 "관련 없음" 판정 근거를 결과에
3. 축별(방법·데이터·평가) 가중치(계획서 §4 E2 L1) — 입력에 축별 질의가 오면 반영
4. 기존 `search()` 시그니처 유지(추가 인자만). 실측 표를 보고서에
