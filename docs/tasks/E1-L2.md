# E1-L2 — Crossref–Retraction Watch 사후 상태 소스 (앞당김)

- 빌더: Claude Opus 5.5 · 검증: Claude Sonnet 5.5
- 목표 시간: 45분
- 소유: `src/neumann/sources/retraction.py`, `tests/e1/test_retraction*.py`

## 읽을 것

- 계획서 §3 L2 "데이터", §4 E1 L2
- `부록/데이터소스/retraction.md`(필드·조인 방법·함정: 공지 쪽만 매칭되는 방향 문제)
- `부록/설계/02_data_schema.md` §3.5(PostStatus), §4.4(RW 매핑)
- `공개자료/data/retraction_watch/README.md`와 `retraction_watch.csv`(약 67MB, 라이선스 선언 없음 → 출처 표기 필수, 원본 커밋 금지)
- `src/neumann/models.py`(PostStatus)

## 만들 것

1. `src/neumann/sources/retraction.py`
   - CSV → `PostStatus` 레코드(철회·정정·우려표명 등 kind 매핑, `reason_codes`는 원문 그대로, `notice_doi` → 근거 링크 `https://doi.org/...`, provenance)
   - 공유 데이터 폴더 `data/processed/retraction.jsonl` + `retraction_manifest.json`(건수, kind 분포, sha256, 소요 시간)
   - `get_post_status(doi: str) -> list[PostStatus]`(원논문 DOI 기준, 정규화)
   - `field_failure_prior(subject_keywords: list[str]) -> dict`: 분야별 철회 사유 빈도(카드의 "이 분야에서 흔한 사후 문제" 근거용)
   - 코퍼스(ICLR 논문)와의 조인 결과: DOI가 있는 논문 수, 매칭 수(0이어도 정직하게 보고)
2. 리뷰어·저자 신원 정보는 넣지 않는다(저자 이름 필드 버림)

## 완료 기준

1. 건수·kind 분포·DOI 정규화 규칙 보고
2. 테스트: 알려진 DOI 몇 건(CSV에서 뽑은 실제 행)으로 조회 일치, 없는 DOI는 빈 목록, 신원 필드 0
3. `python -m pytest tests/e1 -q`(자기 테스트), `python scripts/verify.py` 통과. 데이터 파일 커밋 금지
