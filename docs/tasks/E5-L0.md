# E5-L0 — 근거 연결 검사기 (앞당김)

- 빌더: Claude Opus 5.5 · 검증: Claude Sonnet 5.5
- 목표 시간: 45분
- 소유: `eval/linkage.py`, `tests/e5/test_linkage*.py`

## 읽을 것

- 계획서 §3 L0 완료 기준 2·3, §4 E5 L0("폐기율과 함께 보고", "오프셋 0은 정상값", "조작 인용을 주입하면 1.0 아래")
- `04_평가_명세.md` §2.2(근거 연결률 정의), §6(함정)
- `src/neumann/models.py`(Excerpt, RiskCard, PremortemResult)

## 만들 것

1. `eval/linkage.py`
   - `check_result(result: PremortemResult, source_lookup) -> LinkageReport`: 카드의 모든 근거 Excerpt에 대해 원문[start:end] == 인용 텍스트, 해시 일치, 원문 URL 존재를 검사
   - `source_lookup`은 excerpt의 source_id로 원문 텍스트를 돌려주는 함수(코퍼스 저장소 또는 fixture)
   - 보고: 근거 연결률(통과/전체), 카드 단위 통과율, 폐기율(파이프라인이 버린 지적 수 / 전체 지적 수 — 결과에 있으면), 실패 목록(카드 id, excerpt id, 사유)
   - CLI: `python -m eval.linkage --result <result.json> --out <report.json>`
2. 자체 검사(테스트): 조작 인용 1건 주입 → 연결률 < 1.0, 오프셋 0 발췌 통과(falsy 버그 방지), 해시만 틀린 경우 실패, URL 빈 경우 실패, 폐기율 없는 결과는 "폐기율 없음"을 명시
3. PM이 나중에 `scripts/verify.py`에서 부를 수 있게 함수 하나로 호출 가능하게

## 완료 기준

1. `python -m pytest tests/e5 -q` 통과(fixture 결과로)
2. fixture RiskCard로 CLI 실행 결과를 보고서에
3. `python scripts/verify.py` 통과
