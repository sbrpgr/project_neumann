## 고칠 것 (PASS-조건부)

1. **16쪽 각주·03행의 옛 실측 문구**(빌더가 그대로 두고 표시함). "수집 300편 14~20분 · 색인 1,200편 약 9분 실측", "10만 편 색인은 CPU로 약 12시간". 이 중 색인 9분은 E2-L0.md 참고치의 옛 CPU 빌드(1,200편×3축 536.9초 ≈ 9분)와 맞는 옛 제품 측정이고, 현재 제품은 1,128편 GPU 약 76초다. "수집 300편 14~20분"은 main의 보고서·decisions 어디에도 근거가 없다(검색 0건). README 지킬 것("현장에서 잰 값만")과 충돌한다. 최종 제출본 전에 PM이 현재 실측(E1-L0 수집 12~20초, E2-L0 색인 76초)으로 바꾸거나 근거 없는 수치를 빼야 한다.
