# 백테스트 n=5 결과 (E5-L2b·E5-L2c)

- **n=5(대표 결정, 비용 사유; 30 → 15 → 5), real 조건만(셔플 대조 없음), 통계적 결론을 내리지 않는다.**
- 표본: 사전 등록 표본(`backtest_sample.json`, list_sha256 확인)의 앞 5편(거절 3·채택 2). 분야는 PDE 4·재료/단백질 1로 치우쳐 있다.
- 모델: Neumann·일반 LLM 기준선 모두 `gpt-6.1-sol`. 판정: Claude Sonnet 3명(서로 격리, 다수결). 대표 판정은 제품을 아는 대표라 사실상 비블라인드.
- Neumann 5편 중 3편은 카드 0장이다. 입력(초록 조각, 153~510자)이 적합성·검색어 단계에서 "연구계획서 아님/판정 보류"로 멈췄다(E5-L2d 진단). 이것도 빼지 않고 적중 0으로 센다.
- 블라인드 경과(결정 22:2x·23:1x): 1차 봉투는 Neumann 설명 앞머리 조사("은 ")가 단서여서 중단·무효(`judge_n5_invalid_blindleak/`). 2차(`judge_n5`)는 조사를 지웠으나 Neumann 4/4에만 있는 근거 출처 문장("유사 연구의 리뷰어들은 … 지적")이 남은 **부분 블라인드**. 3차(`judge_n5v3`)는 사전 등록 규칙("근거 인용 제거")대로 그 문장을 두 시스템 모두에서 지웠다 — **주 결과**. 남은 단서: Neumann 설명이 더 짧음(평균 113자 대 152자), 현재형 어미.
