- 브랜치 `task/E4-S06` (main `8f77957` 기준), 빌더 claude-opus-5.5
- 근거: `docs/reports/SEC-1.md` S-06("계획서가 OpenAI로 전송된다는 고지와 기밀·개인정보 입력 금지 문구가 화면에 없다")

## 무엇을 했나

입력 화면(`src/neumann/webui/index.html`)의 입력 카드 안, **실행 버튼 줄 바로 위**에 전송 고지를 넣었다. 직접 입력·파일 업로드 두 모드가 같이 쓰는 자리라 두 모드 모두 같은 고지가 나온다.

넣은 문구(라벨 + 두 줄):

> **외부 전송**
> 입력한 계획서는 분석을 위해 OpenAI API(gpt-6-astra)로 전송됩니다. 개인정보·미공개 기밀은 넣지 마세요.
> 이 서버는 계획서 본문을 파일로 저장하지 않습니다(분석 결과는 메모리에 잠시 보관).

- 글은 `SEND_NOTE` 상수 한 곳에만 있고, `paintSendNote()`가 `createElement` + `textContent`로 칠한다(innerHTML·문자열 이어 붙이기 없음). `aria-label`도 `setAttribute`로 넣는다. `role="note"`.
- 스타일 `.sendnote`: 색은 `:root` 토큰만(`--card` 배경, `--line2` 겹선, `--text2` 본문, 라벨만 `--red`), 한글에 자간·uppercase·모노 없음, 왼쪽 색 바·알약·둥근 모서리 없음. 괘선은 기존 `.fit`·`.sec`처럼 위 겹선.
- **`position: sticky; bottom: 0`**: 자연 위치는 실행 버튼 바로 위(간격 18px)이고, 버튼이 첫 화면 밖에 있을 때는 화면 아래 끝에 붙어 보인다(아래 "결정 1").
- CDN·외부 요청 추가 없음.

## 결정

1. **"실행 버튼 가까이"와 "첫 화면 안"이 1440×900에서 동시에 안 된다.** 직접 입력 모드에서 실행 버튼은 y≈1163(히어로 + 340px 입력칸 아래)이라 첫 화면 밖이다. 히어로·입력칸을 줄이는 것은 소유 밖이라, 고지를 버튼 바로 위에 두고 `position: sticky; bottom: 0`으로 붙였다. 첫 화면에서는 화면 아래 끝(입력 카드 안)에 보이고, 내리면 버튼 18px 위 제자리에 선다. 대가: 첫 화면에서 입력칸 아래쪽 약 64px를 덮는다(입력칸은 내리면 다 보인다). 업로드 모드(파일 없음)는 자연 위치 그대로 첫 화면 안.
2. **문구는 과제 지시문 그대로** 두 문장 + 라벨 "외부 전송"(명사형). 05_디자인_규칙에 명사형 종결 규칙은 없다(`grep 명사형` 0건). §6은 "~하지 않습니다 류의 안심 문구"를 금하지만, 이 고지는 SEC-1이 요구한 데이터 처리 사실 고지라 윤리 각주와 같은 부류로 보고 넣었다(기존 추적 섹션 각주도 "~아닙니다" 문장).
3. **사실 확인(문구 → 코드):**
   - "OpenAI API(gpt-6-astra)로 전송": 제품 분석 경로(E3-L0 `pipeline`·`llm`, 설정 기본 `llm_model="gpt-6-astra"`) 기준. **지금 main(8f77957)에는 `neumann.pipeline`이 없어 샘플 경로로 돌고 실제로는 어디에도 보내지 않는다**(헤더에 "분석 파이프라인 미연결(샘플 데이터)" 표시). 보내지 않는데 보낸다고 쓰는 쪽이라 사용자 보호 방향이고, 파이프라인 병합 뒤에는 사실이 된다. `NEUMANN_LLM_MODEL`로 모델을 바꾸면 문구도 바꿔야 한다.
   - "본문을 파일로 저장하지 않습니다": main의 `api/main.py`는 파일을 쓰지 않고, 로그는 오류 사유 한 줄(`log.error(why)`)뿐이다. E3-L0 `analyze/extract.py`의 디스크 캐시는 코퍼스 심사평에서 뽑은 지적(issues)을 담는다(코드 훑어본 범위).
   - "(분석 결과는 메모리에 잠시 보관)": 지금 main에는 결과 보관 자체가 없다(요청마다 돌려주고 끝). **미병합 E4-L2c(`7738eb0`)는 공개 프로필에서 결과를 `data/cache/results/<plan_id>.json` 파일로 남긴다**(본문 줄은 `_strip_plan_body`로 뺌). 병합되면 괄호 문장이 사실과 달라진다 → `test_store_line_matches_result_cache`가 그때 실패하고 바꿀 문구를 알려 준다(예: "…저장하지 않습니다(분석 결과는 본문 줄을 뺀 채 캐시에 보관)."). 지금은 건너뜀.
   - "모델 학습에 쓰지 않는다"류는 쓰지 않았다(`llm.py`의 `store: False`는 우리 쪽 요청 옵션일 뿐 학습 여부를 우리가 확인할 수 없다). 검사기가 막는다.
4. 고지 글은 HTML 문자열에 넣지 않고 빈 자리만 문자열로 만든 뒤 칠한다. 이를 위해 `render()` 입력 분기에 `paintSendNote()` 호출 한 줄을 붙였다(고지 연결에 필요한 최소 변경).
