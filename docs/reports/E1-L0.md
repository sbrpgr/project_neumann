## 무엇을 했나

1. **탐색:** papers parquet(49,418행, 1 row group)와 리뷰 샤드 0·1(137,195행씩)의 스키마를 확인했다. 샤드 0은 전부 ICLR 2025, 샤드 1은 ICLR 2025 53,738 + ICLR 2024 83,457 노트다. 노트 종류는 제목으로 갈린다: `Official Review by …`, `Meta Review of Submission… by Area_Chair_…`, `Paper Decision`, `Response by Authors|Reviewer|…`. `content`는 JSON이다. 원본 텍스트는 줄바꿈이 이미 빠져 있다(`- A.- B.` 형태, 원본 그대로).
2. **선별:** ICLR 2024·2025 논문 14,451편 중 데스크 리젝 123편을 뺀 심사 논문 14,328편에서 제목+초록 키워드로 3개 분야를 고른다. 키워드는 `src/neumann/sources/researcharcade.py`의 `FIELD_KEYWORDS` 상수(분야별 46·50·56개)이고, 규칙 전체의 sha256을 manifest에 남긴다.
3. **연결:** `replyto` 사슬을 논문까지 거슬러 올라가 붙인다. 공식 심사평·메타리뷰 → `ReviewEvent`, 저자 답변(`writer == "Authors"`) → `AuthorResponse`(답변의 답변도 가장 가까운 공식 심사평에 연결), `Paper Decision` 노트 + papers의 `paper_decision` → `Decision`. 결정 문자열은 확장 매핑(`DECISION_RULES`)으로 바꾼다. 밑줄을 공백으로 바꾸고 대소문자를 무시한 뒤 철회 → 데스크리젝 → reject → oral → spotlight → poster → accept 순서로 본다.
4. **모델 변환:** main의 `models.py`(E0b, def820d 병합)로 검증한 뒤 공유 데이터 폴더 `data/processed/`에 엔티티별 JSONL로 쓴다. 순서가 정해져 있어 같은 입력이면 같은 바이트가 나온다.
5. **manifest:** `data/processed/corpus_manifest.json`에 편수, 분야별 수, 분야 조합, 심사평 수, 결정 분포·거절 비율, 키워드 해시, 입력 파일 sha256(공개자료 manifest와 대조), 출력 파일별 sha256, 소요 시간, 사전 집계를 기록한다.
6. **조회 인터페이스:** `src/neumann/sources/corpus.py`의 `load_corpus(data_dir)`와 전량 검사기 `audit_processed(data_dir)`를 두었다.

## 결정 (스펙이 모호해서 고른 것)

1. **키워드는 정밀도를 우선했다.** 초안 목록(단어 단위)을 실제로 돌려 맞은 글을 눈으로 확인했다. 뜻이 여럿인 단어는 과학 쓰임새의 구로만 남겼다. 초안의 합집합은 2,057편이었다. 주요 오탐은 다음과 같았다.
   - `material` → "supplementary material"
   - `catalyst` → "a catalyst for", `battery` → "a battery of tests"
   - `physics` → "Physics of Language Models", `dynamical system`·`quantum`(양자 알고리즘)은 일반 ML
   - `weather` → "weather conditions", `fluid` → "fluid motion", `ocean` → "Oceania"·"OCEAN"
   - `genome` → "Visual Genome", `biological`·`neuroscience` → 생물 영감 ML
   - `clinical`·`disease`·`medicine` → 의료 ML
   - `ogbn-proteins`는 그래프 ML 벤치마크 이름이라 매칭 전에 지운다(`MASK_PHRASES`, 2편 감소)

   그 결과 1,128편이 됐다(사전 집계 1,265). 사전 집계의 키워드 목록은 받지 못해 1:1로 비교하지 못했다. 신경과학·의료영상은 3개 분야 정의에 없어서 넣지 않았다. 계획서 §4 E1 L1도 이 분야(데모 2·3번)를 eLife·PLOS로 보강한다고 적고 있다.
2. **모집단에서 데스크 리젝을 뺐다**("심사 논문"). 철회 논문은 papers에 없다.
3. **원문 해시(`content_sha256`)** 는 받은 원문을 NFC·LF 정규화한 뒤의 sha256이다(models 정의). 대상은 다음과 같다.
   - 심사평·답변: 노트 `content` JSON 문자열
   - 논문: papers 행 전체의 canonical JSON
   - 결정: {papers 행, 결정 노트} canonical JSON
4. **접근 시각(`accessed_at`)** 은 공개자료 `manifest.json`의 파일별 `retrieved_at_utc`다(2026-09-28T10:25:28Z 등). manifest가 없으면 파일 수정 시각을 쓴다. 실행 시각을 쓰지 않아 출력이 결정적이다.
5. **`created`** 는 ResearchArcade `time`에 시간대 표기가 없어 UTC로 해석했다.
6. **`reviewer_pseudonym`은 쓰지 않았다.** 심사평과 답변은 `review_id`로 연결되므로 필요 없다. 솔트(`NEUMANN_PSEUDONYM_SALT`)는 main 체크아웃의 `.env`에만 있어 worktree에서 쓰면 결과가 환경에 따라 달라진다. 그래서 검사기는 pseudonym 키도 신원 키로 거부한다.
7. **보일러플레이트 제거:** 빈 칸과 점수 칸(Soundness·Presentation·Contribution, 텍스트 밖)을 뺐다. `Rating`·`Confidence`는 모델 필드에 원문 문자열로 넣었다. "See above." 같은 짧은 답도 실제 원문이므로 지우지 않았다.
8. **신원 제거:** models의 `redact_pii`(이메일·ORCID)에 더해 OpenReview 프로필 id(`~Jane_Doe1`)를 `[PROFILE]`로 가린다. 저자 답변 본문에 남은 익명 리뷰어 핸들(예 "Reviewer 8LjP")은 OpenReview가 공개하는 포럼 단위 익명 id라 그대로 두었다.
9. **ReviewEvent로 넣지 않은 것:** 리뷰어·AC 토론 댓글(`Response by Reviewer` 등 3,777건)과 실명 공개 댓글(72건)은 L0 범위 밖이라 넣지 않았다. 스키마의 `reviewer_comment` 종류로 L1에서 더할 수 있다.

## 못 한 것

- 리뷰 샤드 2~5는 공개자료에 없다. 그래서 60편(대부분 ICLR 2024)은 심사평이 없다(L3).
- 선별 결과(1,128편)가 사전 집계(1,265편)와 다르다. 사전 집계의 원래 키워드 목록이 없어 차이를 항목별로 설명할 수 없다. 넓히려면 `FIELD_KEYWORDS`에 추가하고 다시 돌리면 된다(키워드 해시가 바뀐다).
- 검증자 표본 20건 대조(계획서 §4 E1)는 검증자 몫이다. `--check-sample 20 --seed <다른 값>`으로 바로 돌릴 수 있다.

## 제안 (계약 변경은 PM 판단)

- `ReviewEvent`에 `soundness`·`presentation`·`contribution`(원문 문자열) 칸을 추가하면 점수 칸을 버리지 않아도 된다(02_data_schema §3.2에는 있다).
- `Provenance`에 `attribution` 칸을 추가하면 좋겠다. 라이선스 미선언 소스의 출처 표기 강제(02_data_schema §1)를 레코드 단위로 지킬 수 있다. 지금은 manifest의 `attribution`에만 있다.
- `verify.py`의 훅 경고가 절대경로 `core.hooksPath`를 인식하지 못한다(오경고).

## PM 정정 (검증 반영, 2026-09-30 19:00)

- **사전 집계 비교 기준:** 모집단 13,433편은 리뷰 샤드 0·1에서 공식 심사평이 1건 이상 있는 논문 수다(검증자가 직접 재계산). 같은 기준으로 비교하면 **1,068편 대 1,265편(-15.6%)**이다. 1,128편에는 심사평 없는 60편이 포함돼 있다. 물리 분야는 사전 집계보다 +102편 많아서 "키워드를 좁혀서 줄었다"는 설명만으로는 차이를 설명하지 못한다.
- **선별 오탐률:** 무작위 20편 판정에서 오탐 8편(경계 사례를 적중으로 보면 5편), 층화 표본을 더한 전체 추정 **약 30%(25~40%)**. 원인은 초록의 응용 예시에서 넓은 단어(`molecul*`·`drug*`·`climate`)가 걸린 경우다. "정밀도를 우선했다"는 문구는 측정하지 않은 주장이라 철회한다. 발표에서는 "키워드 선별 1,128편"으로 쓴다.
- **강한 층:** 제목 적중 600편 + 키워드 2개 이상 210편 = 810편. 백테스트 표본은 이 층에서 뽑는다(결과를 보기 전 결정, `docs/decisions.md`).
